# DSSI (Data Science for Social Impact) Curriculum

This repository contains the materials used to teach students during the first few weeks of the DSSI Summer program. There are directories containing materials from each year the program has run. Each directory contains ipynb and data files for the content taught that year as well as a README.md file describing the order in which is was taught and how long each module lasted. Content was presented using Jupyter Slides which students could open on their own machines as Jupyter Notebooks. The curriculum contains a mixture of lectures, labs, activities, and homework assignments.

Authors of these files include:

## Curriculum Evolution (2023–2025)

### **2023 — Foundational Baseline**

* **Duration:** 1 instructional week
* **Primary focus:** Core Python and data science foundations
* **Key topics:**
  * Python basics
  * Data structures
  * pandas and DataFrames
  * Visualization fundamentals
  * Sampling and hypothesis testing
  * Linear regression
  * Conceptual prediction

---

### **2024 — Expanded Foundations & Applied Methods**

* **Duration:** 1 instructional week + required prework
* **Additional Topics:**
  * Structured prework (Python, Jupyter, regex, ethics)
  * Documentation and reproducibility
  * Regular expressions
  * Explicit data ethics module
  * Introduction to classification and machine learning

---

### **2025 — Two-Week Curriculum with ML & NLP**

* **Duration:** 2 instructional weeks
* **Week 1:** Identical to 2024 foundational curriculum
* **Week 2:** Machine learning and natural language processing

**Week 2 topics include:**

* Neural networks
* Text representation and embeddings
* Language modeling
* RNNs and LSTMs
* Attention mechanisms
* Transformer-based models (e.g., BERT)
* Applied NLP tasks (classification, token tagging, generation)

**Key tools introduced:**

* `scikit-learn`
* `PyTorch`
* `NLTK`
* `SpaCy`
