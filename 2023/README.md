# Data Science for Social Impact (DSSI) - Summer 2023 Curriculum

## Overview

This directory contains the instructional materials used during the **Summer 2023 Data Science for Social Impact (DSSI) program**. The materials are organized to reflect **what was actually taught in the order it was taught.**

The 2023 program represents a **foundational iteration** of the DSSI curriculum. Its primary goal was to establish a shared baseline in core data science tools and concepts that later cohorts would build on through more project-focused work.

This README is written so that someone **not involved in the 2023 program** can understand the instructional progression, organization, and pedagogical intent.

---

## Program Scope (2023)

- **Duration:** One instructional week (Monday–Friday)
- **Primary focus:** Core data science foundations
- **Project emphasis:** Limited; emphasis was placed on shared technical grounding rather than extended project work

---

## Weekly Schedule and Instructional Mapping

The Summer 2023 program ran over **five instructional days**, corresponding directly to **Lectures 1–5** in this repository:

| Day       | Repository Label | Theme                                  |
| --------- | ---------------- | -------------------------------------- |
| Monday    | Lecture 1        | Orientation & Core Tooling             |
| Tuesday   | Lecture 2        | Data Structures & DataFrames           |
| Wednesday | Lecture 3        | Statistics Foundations & Visualization |
| Thursday  | Lecture 4        | Statistical Inference & Regression     |
| Friday    | Lecture 5        | Prediction & Conceptual Modeling       |

This mapping is intentional: **lecture numbering corresponds directly to the day of instruction**.

## Instructional Progression (Monday–Friday)

### Day 1 (Monday): Orientation & Core Tooling

* Program welcome and onboarding
* GitHub account setup
* Introduction to JupyterLab
  * Cells and cell types
  * Kernel management
  * Saving and running notebooks
* Python basics
  * Data types
  * Operations and comparisons
  * Assignment statements
  * Built-in functions
  * String methods

---

### Day 2 (Tuesday): Data Structures & DataFrames

* Lists, arrays, and dictionaries
* Introduction to pandas
* Creating DataFrames and Series
* Reading CSV files and working with file paths
* DataFrame structure (index, columns, shape)
* Accessing, slicing, and conditional selection
* Iteration and conditionals
* User-defined functions

---

### Day 3 (Wednesday): Statistical Foundations & Visualization

* Correlation and interpretation
* Sampling and potential sources of bias
* Distributions and empirical distributions
* Statistics vs. parameters
* Introductory visualization principles
* Building and interpreting basic plots

---

### Day 4 (Thursday): Statistical Inference & Regression

* Hypothesis testing workflow
* Interpretation of p-values
* Introduction to regression modeling
* Linear regression and output interpretation
* Connecting statistical inference to modeling decisions

---

### Day 5 (Friday): Modeling & Conceptual Prediction

* Linear regression review and extensions
* Conceptual overview of machine learning
  * Supervised vs. unsupervised learning
* Discussion of prediction in applied contexts
* Synthesis of the week’s material
