# Data Science for Social Impact (DSSI) — Summer 2024 Curriculum

## Overview

This directory contains the instructional materials used during the **Summer 2024 Data Science for Social Impact (DSSI) program**. Materials are organized to reflect **what was actually taught** in the order it was taught.

The 2024 program builds directly on the 2023 foundation but introduces **meaningful expansions in scope**, including:

- structured prework,
- documentation and workflow skills,
- regular expressions,
- data ethics,
- and a clear introduction to classification and machine learning.

This README is written so that someone **not involved in the 2024 program** can understand the instructional progression, organization, and pedagogical focus.

---

## Program Scope (2024)

- **Duration:** One instructional week (Monday–Friday), plus prework
- **Primary focus:** Core data science foundations with expanded tooling and applied methods
- **Project emphasis:** Limited, but with clearer preparation for future project-based work
- **Key differences from 2023:**
  - Required prework prior to Week 1
  - Explicit instruction in documentation and reproducibility
  - Introduction of regular expressions and data ethics
  - Expanded modeling content (classification + ML overview)

Only materials that were **actively used during instruction** are included in this directory.

---

## Prework (New in 2024)

Unlike 2023, the 2024 program included **required prework** designed to ensure a shared baseline before the instructional week began.

### Prework Topics

- Getting started with Python and Jupyter notebooks
- Collections of data
- Installation and setup instructions
- Regular expressions
- Data ethics and responsible data use

Prework materials are located in: 2024/Lectures/Prework/

## Weekly Schedule and Instructional Mapping

The instructional week ran **Monday–Friday**, corresponding directly to **Lectures 1–5**.

| Day       | Repository Label | Theme                                     |

## Instructional Progression (Monday–Friday)

### Day 1 (Monday): Pandas, DataFrames, and Grouping

* Welcome and orientation
* Review of Python and notebook fundamentals (building on prework)
* DataFrames and tabular data
* Groupby, pivot tables, and aggregation
* Applied activities using real datasets

---

### Day 2 (Tuesday): Visualization and Exploratory Analysis

* Visualization principles
* Building and interpreting plots
* Exploratory data analysis workflows
* Connecting visualizations to analytical questions

---

### Day 3 (Wednesday): Probability, Distributions, and Functions

* Probability and distributions
* Empirical vs. theoretical reasoning
* Documentation and reproducibility
* User-defined functions
* Lab-based reinforcement

---

### Day 4 (Thursday): Classification and Machine Learning

* Classification fundamentals
* Binary and multi-class classification
* Model intuition and evaluation
* High-level machine learning overview

---

### Day 5 (Friday): Data Ethics and Text Processing 

* Ethical considerations in data science and modeling
* Introduction to text processing concepts
* Regular expressions (regex)
* Course synthesis and wrap-up
